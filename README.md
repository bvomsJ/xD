# PROBIV-style forum demo

Интерактивный визуальный макет по предоставленным референсам.

Особенности:
- старая форумная эстетика: бежевый фон, таблицы, тонкие рамки;
- кликабельные темы;
- кликабельные рекламные блоки;
- демонстрационные модальные окна;
- адаптивная мобильная версия;
- CSS-анимация верхнего рекламного блока;
- все данные синтетические.

Запуск: откройте `index.html` в браузере.

Это именно демонстрационный макет: реальные базы данных, пробив, утечки и чужие персональные данные не подключены.
